# ⚽ Futebol Brasil

### A paixão pelo futebol brasileiro em um só lugar! 🇧🇷

O **Futebol Brasil** é uma plataforma desenvolvida para reunir informações sobre o futebol masculino brasileiro, permitindo que os usuários conheçam os principais clubes, suas histórias, estádios, mascotes, títulos e curiosidades.

O projeto foi desenvolvido utilizando **HTML5, CSS3 e JavaScript**, com foco em interatividade, organização e experiência do usuário.

---

## 🌐 Acesse o projeto

🚀 **Site online:** [Futebol Brasil](https://projeto-do-futebol-brasileiro.vercel.app/)

---

## 📌 Sobre o projeto

O objetivo do Futebol Brasil é criar uma plataforma informativa onde os apaixonados por futebol possam conhecer melhor os principais clubes brasileiros e explorar informações relevantes sobre o cenário nacional.

A plataforma possui uma interface intuitiva, responsiva e dinâmica, facilitando a navegação e a pesquisa por clubes.

## 🚀 Funcionalidades

- 🏠 **Página inicial:** apresentação do portal Futebol Brasil.
- 🏆 **Competições:** informações sobre Brasileirão, Copa do Brasil, Libertadores e campeonatos estaduais.
- ⚽ **Pesquisa de clubes:** busca dinâmica pelo nome dos times.
- 🛡️ **Informações dos clubes:** nome completo, escudo, fundação, localização e cores oficiais.
- 🏟️ **Estádios:** informações sobre os estádios dos clubes.
- 🐾 **Mascotes:** identificação dos mascotes dos times.
- 🥇 **Títulos:** apresentação das principais conquistas.
- 📖 **História:** informações sobre a trajetória dos clubes.
- 📱 **Responsividade:** adaptação para computadores, tablets e celulares.
- 🔎 **Sugestões de pesquisa:** apresentação de clubes conforme o texto digitado.
